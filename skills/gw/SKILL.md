# gw — 그룹웨어 도우미 (연구원용)

셸에서 `gw <명령>` 을 실행한다. 명령별 옵션은 `gw <명령> --help` 가 정본이다 — 여기 적지 않은 옵션은 도움말을 먼저 본다.

## 전제

- **먼저 `gw version-check 2026.10.30.3` 를 실행한다.** 실패하면(명령이 없다는 오류 포함) 출력 한 줄을 사용자에게 그대로 보여 주고 멈춘다 — 런타임이 이 스킬보다 오래된 것이니 jaix-setup 을 다시 실행해야 한다. `gw` 명령 자체가 없을 때도 같다.
- **원내망(또는 VPN)에서만** 동작한다. 연결이 안 되면 `gw probe` 로 먼저 진단한다.
- 본인 그룹웨어 계정만 쓴다. 다른 사람의 결재·근태는 조회할 수 없다.
- **첫 사용이면 `gw login` 을 실행한다.** 사용자 화면에 입력 창이 뜨고(터미널이면 그 자리에서) 사용자가 아이디·비밀번호를 **직접** 넣는다. 로그인에 성공하면 이 PC 의 자격 증명 저장소에 저장되고, 이후 명령은 저장된 정보로 로그인한다.
- **`gw login` 은 한 번만 실행하고 종료 코드대로 한다.** 다시 띄우는 것은 사용자가 원한다고 답한 뒤에만 한다.
  - 0: 로그인·저장 완료.
  - 2 (로그인 실패): 대개 아이디·비밀번호가 틀린 것이다. 그룹웨어 고장으로 단정하지 말고, 사용자에게 확인한 뒤 다시 시도할지 묻는다.
  - 3 (취소): 사용자가 창을 취소했거나 5분 동안 입력하지 않았다. **창이 안 보였다고 짐작해 다시 실행하지 말고**, 로그인을 계속할지 사용자에게 묻는다.
  - 4 (창을 띄울 수 없음): 아래 "막힐 때" 를 따른다.
- **조회 명령(`approvals`·`attendance`·`trip-list` 등)이 종료 코드 2와 "로그인이 필요합니다" 로 끝나면 결과가 0건인 것이 아니다.** 조회를 못 한 것이니 "없음"으로 전하지 말고, 로그인 정보가 없거나 만료됐다고 알린 뒤 `gw login` 을 할지 묻는다.
- **비밀번호를 대화에 쓰게 하거나 받지 않는다.** 사용자가 대화창에 비밀번호를 적으면 쓰지 말고, 지금 바로 그룹웨어에서 비밀번호를 바꾸라고 안내한 뒤 `gw login` 창에 직접 넣게 한다. 비밀번호를 명령 인자로 넘기는 방법은 없다.

## 반드시 지킬 것

1. **상신(결재 올리기)은 확인 코드로만 한다.**
   - 먼저 `--dry-run` 으로 실행한다. 미리보기(제목·본문 요약·결재선·첨부 목록)와 확인 코드가 나온다.
   - **미리보기를 사용자에게 그대로 보여 주고, 사용자가 '상신'이라고 답한 뒤에만 `--confirm <코드>` 를 실행한다.**
   - **확인 코드를 스스로 이어서 쓰지 않는다.** `--dry-run` 결과를 보자마자 같은 턴에 `--confirm` 을 붙이지 않는다.
   - 코드는 10분 안에 한 번만 쓸 수 있다. 미리보기 뒤에 기안전이 바뀌면 거부된다 — 그때는 `--dry-run` 부터 다시 한다.
   - 상신이 끝나면 결과표의 **문서번호**를 사용자에게 알려 준다.
2. **기안전 저장·회의실 예약·예약 취소·기안전 삭제**도 실행 전에 무엇을 할지 보여 주고 확인을 받는다.
3. 사용자가 시키지 않은 상신·삭제·예약을 하지 않는다.

## 명령 지도

| 하려는 일 | 명령 |
|---|---|
| 회의실 현황·예약·취소 | `gw room list` · `gw room reserve` · `gw room cancel` |
| 근태(지참·연가·조퇴 등) 기안전 | `gw draft <종류> --from HHMM --to HHMM` |
| 근태 기안전 상신 | `gw submit` (목록) → `gw submit <번호> --dry-run` → `--confirm <코드>` |
| 근태 기안전 삭제 | `gw delete` |
| 지각 대조·누락 지참 기안전 | `gw late-check` (`--draft`) |
| 출장 기안전 | `gw trip` · 목록 `gw trip-list` · 삭제 `gw trip-delete` |
| 출장 상신 | `gw trip-submit` (목록) → `gw trip-submit <번호> --dry-run` → `--confirm <코드>` |
| 출장복명 | `gw trip-result` |
| 연구과제 출장 | `gw rp-trip` · `gw rp-trip-list` · `gw rp-trip-delete` |
| 연구과제 회의개최 등록 | `gw meeting` |
| 대외활동 신청 기안전 | `gw external` · 목록 `gw external-list` · 삭제 `gw external-delete` |
| 재직·경력증명서 신청 | `gw cert` · `gw cert-list` · `gw cert-delete` |
| 본인 결재함 | `gw approvals` |
| 결재 본문 내려받기 | `gw download <문서번호>` (`--hwpx`) |
| 본인 근태 기록 | `gw attendance` |
| 과제 예산 잔액 | `gw budget <과제>` |
| 비용결재 출력·제출 추적 | `gw print-queue` · `gw print-mark` |
| 결재선·서식 안내 | `gw line <상황>` · `gw forms` |
| 설정·연결 확인 | `gw info` · `gw probe` |
| 로그인 정보 저장·삭제 | `gw login` (에이전트가 실행하면 입력 창, 사용자가 터미널에서 직접 치면 그 자리에서 입력) · `gw logout` |

## 막힐 때

- "저장된 로그인 정보가 없습니다" · "저장된 아이디·비밀번호로 로그인하지 못했습니다"(비밀번호 변경 등): 사용자에게 알리고 `gw login` 을 한 번 실행한다. 저장한 정보를 지우려면 `gw logout`.
- "입력 창을 띄울 수 없습니다": 원격·화면 없는 환경이다. 사용자에게 터미널(명령 프롬프트)을 열어 직접 `gw login` 을 실행하라고 안내한다.
- "그룹웨어 주소 설정이 없습니다": jaix setup 을 다시 실행하게 한다(원내망에서).
- "결재선 미정"으로 자동 상신이 안 되는 건은 그룹웨어 화면에서 사람이 상신한다.
- 도외·국외 출장은 자동 상신하지 않는다 — 기안전까지 만들고 화면에서 상신하도록 안내한다.
